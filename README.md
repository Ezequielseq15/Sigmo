# SIGMO — Frontend

sistema integrado de gestion monografica

## Requisitos
- Node.js LTS
- npm
- Visual Studio Code

## Instalación

```powershell
npm install
```

## Ejecutar en desarrollo

```powershell
npm run dev
```

Abrir:

http://localhost:5173

## Construir para producción

```powershell
npm run build
```

## Nota

este proyecto tiene el proposito de ayudar a mejorar 
la gestion de monografias en las universidades
